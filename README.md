## 🧠 Multiplication Brain Game

Ένα διαδραστικό παιχνίδι μνήμης (Memory Match) για την εκμάθηση της προπαίδειας, σχεδιασμένο για να κάνει τη μάθηση διασκεδαστική. Το παιχνίδι τρέχει απευθείας στον browser μέσω του GitHub Pages.

## 🎮 Πώς παίζεται
1. Επιλογή: Επιλέξτε τους αριθμούς της προπαίδειας που θέλετε να εξασκήσετε από την αρχική οθόνη και πατήστε **🚀 ΞΕΚΙΝΑΜΕ!**.
2. Απομνημόνευση: Έχετε 15 δευτερόλεπτα για να δείτε όλες τις κάρτες ανοιχτές και να απομνημονεύσετε τις θέσεις τους!
3. Αντιστοίχιση: Βρείτε τα ζευγάρια συνδυάζοντας τη λευκή κάρτα (Πράξη) με τη ροζ κάρτα (Αποτέλεσμα).
4. Σκοπός: Ολοκληρώστε το παιχνίδι στον λιγότερο δυνατό χρόνο και με τις λιγότερες προσπάθειες. Στο τέλος, σας περιμένει μια έκπληξη με κομφετί! 🎊


## ✨ Χαρακτηριστικά
* **Preview Mode: Σύστημα 15-δευτερόλεπτης απομνημόνευσης πριν ξεκινήσει το παιχνίδι.
* **3D Flip Animations: Ομαλή εναλλαγή των καρτών με CSS3 3D transforms.
* **Smart Matching Logic: Οι κάρτες είναι χρωματικά κωδικοποιημένες (λευκό για ερωτήσεις, ροζ για απαντήσεις).
* **Custom Branding: Ενσωματωμένο διανυσματικό λογότυπο (SVG) και παιχνιδιάρικη γραμματοσειρά Fredoka One.
* **Responsive Design: Πλήρως προσαρμοσμένο για χρήση σε υπολογιστές, tablet και κινητά τηλέφωνα.

## 🛠️ Τεχνολογίες
* HTML5: Δομή και περιεχόμενο.
* CSS3: Flexbox, Grid Layout και Keyframe Animations.
* JavaScript (Vanilla): Μηχανή παιχνιδιού, τυχαία ανακάτεμα καρτών και διαχείριση κατάστασης (State Management).
* Canvas Confetti: Για τα εφέ εορτασμού στη νίκη.ut
